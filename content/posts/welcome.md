ဒီနေရာဟာ နည်းပညာဆိုင်ရာ မှတ်စုများ၊ လေ့လာတွေ့ရှိချက်များနဲ့ ကိုယ်ပိုင်အတွေးအမြင်များကို မြန်မာဘာသာဖြင့် စုစည်းထားတဲ့ နေရာတစ်ခုပါ။

## ဒီ Blog ရဲ့ အယူအဆ

စာမျက်နှာတစ်ခုဟာ အလှဆင်မှုများစွာ မလိုအပ်ပါဘူး။ စာသားကို ဖတ်ရလွယ်ကူစေခြင်း၊ အကြောင်းအရာကို ရှင်းလင်းစွာ စီစဉ်ခြင်းနဲ့ လိုအပ်တဲ့အချက်ကို အလွယ်တကူ ရှာတွေ့စေခြင်းက ပိုအရေးကြီးပါတယ်။

- **ဖတ်ရှုရလွယ်ကူမှု** — နူးညံ့တဲ့ စာရွက်သားနောက်ခံနဲ့ သင့်တော်တဲ့ စာကြောင်းအကွာအဝေး။
- **ရိုးရှင်းမှု** — မလိုအပ်တဲ့ animation နဲ့ အလှဆင်မှုတွေကို ရှောင်ရှားခြင်း။
- **ဖွင့်လှစ်မှု** — Markdown ဖိုင်များနဲ့ ရိုးရှင်းတဲ့ publishing workflow။
- **နည်းပညာကို နားလည်လွယ်စေမှု** — လိုအပ်တဲ့နေရာမှာ ASCII diagram၊ table နဲ့ equation တွေ အသုံးပြုခြင်း။

## Content အသစ် ဘယ်လိုတင်မလဲ?

`content/posts/` directory ထဲမှာ Markdown ဖိုင်အသစ်တစ်ခု ဖန်တီးပါ။ Front Matter ထဲမှာ title၊ date၊ description နဲ့ tags တွေ ထည့်ပြီး ဆောင်းပါးကို ရေးပါ။

ဖိုင်ကို GitHub Repository သို့ Commit လုပ်လိုက်တာနဲ့ GitHub Actions က Website ကို Build လုပ်ပြီး GitHub Pages သို့ Deploy လုပ်ပါလိမ့်မယ်။ ဖုန်းထဲမှာ Hugo ကို Install လုပ်စရာ မလိုပါဘူး။

```text
[ Phone / Tablet ]
        |
        | Markdown
        v
[ GitHub Repository ]
        |
        | Commit / Push
        v
[ GitHub Actions ]
        |
        | Hugo Build
        v
[ GitHub Pages ]
```

## နောက်ဆုံးစကား

နည်းပညာအကြောင်း ရေးသားတဲ့အခါ ရှုပ်ထွေးမှုကို ဖုံးကွယ်ဖို့ မဟုတ်ဘဲ ရှင်းလင်းအောင် ဖော်ပြဖို့ ရည်ရွယ်ပါတယ်။
